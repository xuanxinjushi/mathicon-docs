# Mathicon documentation

Public documentation for **Mathicon** — a Python plotting toolkit for mathematics and machine learning figures.

- Documentation site: https://mathicon.readthedocs.io/
- Package: `pip install mathicon`

This repository contains **Markdown docs only**. It should not include runtime Python source files.

## Edit workflow

Docs are authored from the `mathicon` source tree, then synced to this public docs repo.

Typical local flow:

```bash
cd ~/mathicon
# edit README/dev.md/source docs notes
# then update pages in ~/mathicon-docs/docs
```

If pages and API differ, prefer source-of-truth from `mathicon`.
